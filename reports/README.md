# Reviewed reports

`MILESTONE_2_ANALYSIS.md` is a reviewed **synthetic-data SQL analysis** report. It contains computed simulation results and limited investigative observations, not findings about real customers.

Reproduce it with `.venv/bin/python scripts/run_analysis.py`. The fresh report and CSVs go to ignored `data/generated/analysis/`; the reviewed copy here is not automatically overwritten. Other report files remain ignored by default. Three accepted local dashboards are available in the [final workbook](../release/SYNTHETIC_Growth_REVIEW.twbx). No experiment has been executed. The reviewed Markdown report and fresh generated report serve different purposes; retain the reviewed copy as evidence.
