# Reviewed reports

`MILESTONE_2_ANALYSIS.md` is a reviewed **synthetic-data SQL analysis** report. It contains computed simulation results and limited investigative observations, not findings about Puffy or real customers.

Reproduce it with `.venv/bin/python scripts/run_analysis.py`. The fresh report and CSVs go to ignored `data/generated/analysis/`; the reviewed copy here is not automatically overwritten. Other report files remain ignored by default. No dashboards or successful experiments have been produced.
